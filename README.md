# Putter Daily

สรุปงานและร่างข้อความ LINE รายโครงการ ในนามพัตเตอร์ (ฝ่ายบริหารความยั่งยืนและบริหารโครงการ ปตท.)
ใช้ Dusit Daily เป็นต้นแบบ: หน้าเดียว ไม่มีขั้นตอน build, deploy บน Vercel และ**ไม่มีหน้า login**

## ทำอะไรได้
- **โครงการ** เช่น Good Growth, Sustainability SPARK เพิ่มหรือแก้ไขได้ไม่จำกัด หน้าแรกแสดงภาพรวม: เรื่องที่รอตัดสินใจ รอคำตอบ เลยกำหนด และงานที่ใกล้ถึงกำหนดใน 7 วัน
- **งาน** แบบเดียวกับ Dusit Daily: เลือก **ด่วน · ติดตาม · แจ้งให้ทราบ** และ**แตะวงกลมหน้างานเพื่อติ๊กว่าเสร็จ** (มีปุ่มย้อนกลับ) หน้าโครงการมีแค่ 2 แท็บ "รอทำ | เสร็จแล้ว" เรียงสิ่งที่ต้องทำก่อน: ด่วนหรือเลยกำหนด → มีวันกำหนด (ใกล้สุดก่อน) → ติดตาม → แจ้งให้ทราบ
  เมื่อเปลี่ยนสถานะ กำหนด หรือผู้รับผิดชอบ ระบบบันทึกประวัติให้เอง ใช้บอกว่าเปลี่ยนจากเดิมอย่างไร ข้อมูลเก่าที่มี 6 สถานะแปลงให้อัตโนมัติ
- **Timeline** ในหน้าโครงการ สลับ "รายการ | Timeline" ได้ งานเรียงตามวันกำหนดบนเส้นเวลา มีจุด "วันนี้" งานที่เลยกำหนดเป็นสีแดง แบ่งตามเดือน งานที่ไม่มีกำหนดอยู่ท้ายสุด ติ๊ก "แสดงความเคลื่อนไหว" เพื่อดูว่าวันไหนเปลี่ยนอะไร (สถานะ กำหนด อัปเดต) เลือกงานเพื่อสรุป/ร่าง LINE จาก Timeline ได้เลย
  - **เส้นหมุดหมายด้านบน** แบบ Gantt: เส้นประมีลูกศร เลขสัปดาห์ (W48, W49 …) เส้น "วันนี้" และจุดของแต่ละหมุดหมาย สีตามสถานะ (แดง = เลยกำหนด) ติ๊ก "หมุดหมาย" ในหน้าแก้งานเพื่อเลือกเฉพาะจุดสำคัญ ถ้ายังไม่ติ๊กเลยจะแสดงทุกงานที่มีกำหนด แตะจุดเพื่อเลื่อนไปวันนั้น ถ้าแผนยาว เลื่อนเส้นไปด้านข้างได้
- **เลือกงานที่จะสรุป** ในหน้าสรุปงาน/ร่าง LINE กด "เลือกงาน" แล้วติ๊กเอาออกหรือใส่เพิ่ม ค่าเริ่มต้นคืองานที่ยังไม่เสร็จทั้งหมด
- **วางโน้ตประชุม/ข้อความจากแชต** ในกล่องท้ายหน้าโครงการ (บันทึกให้อัตโนมัติ แยกตามโครงการ)
- **Putter Help** (ปุ่มขวาล่าง) คุยด้วยเสียงหรือพิมพ์ แบบเดียวกับ Dusit Help เช่น
  - ถาม: "มีอะไรค้างบ้าง", "รอคำตอบจากใครอยู่", "เรื่องไหนต้องให้หัวหน้าตัดสิน", "งานใกล้กำหนดสัปดาห์นี้"
  - สั่ง: "พี่นัทยืนยัน Artwork แล้ว", "เลื่อนสรุป Agenda เป็นวันศุกร์", "เพิ่มงานใน SPARK จองห้องประชุม พฤหัส 14.00 พี่บอมดูแล", "สร้างโครงการ …"
  - วางโน้ตประชุมแล้วบอก "เก็บไว้ในโครงการ SPARK" ระบบเก็บไว้ในกล่องโน้ตของโครงการนั้น
  - "สรุปให้หัวหน้า", "ร่างไลน์ตามคุณแอ้เรื่องคิวคุณทีน่า": Putter Help เลือกงาน ผู้รับ และจุดประสงค์ไว้ให้ แล้วกด "เปิด" เพื่อตรวจและคัดลอก
  - ทุกการเปลี่ยนแปลงมีปุ่ม **ย้อนกลับ** และบันทึกประวัติไว้ในงาน · เปิดให้ตอบเป็นเสียงได้ที่ปุ่มลำโพง
  - ไม่มี AI: ใช้แบบพื้นฐาน (ถามรายการตามสถานะ, "… เสร็จแล้ว/ยืนยันแล้ว", "สรุป…", "ร่างไลน์ตามพี่…", จดงานใหม่ พร้อมอ่าน "พรุ่งนี้/วันศุกร์/14.00/พี่X")
- **สรุปงาน** มี 2 แบบ
  - *สรุปให้หัวหน้า:* ขึ้นต้นด้วยผลล่าสุดหรือเรื่องที่ต้องตัดสินใจ ตามด้วย ยืนยันแล้ว / ข้อเสนอที่กำลังหารือ / รอคำตอบ / ใครทำอะไรภายในเมื่อไร / เปลี่ยนจากเดิม
  - *สรุปให้ทีม:* ขึ้นต้นด้วยงานที่แต่ละคนต้องรับไปทำ (จัดกลุ่มตามคน)
- **ร่าง LINE** เลือกผู้รับ (หัวหน้า · พี่ในทีม · คณะทำงาน · ผู้ประสานงานภายนอก) และจุดประสงค์ (แจ้งความคืบหน้า · ตามงาน · ขอคำยืนยัน · ขอให้พิจารณา · แจ้งเปลี่ยนกำหนดการ)
  - พี่ในทีม: "พี่นัทครับ …" เข้าเรื่องเลย · ผู้ประสานงานภายนอกที่ติดต่อครั้งแรก: "สวัสดีครับคุณแนน พัตเตอร์จาก ปตท. ครับ …"
  - แจ้งเปลี่ยนกำหนดการ: ใส่วันเวลาเดิมและใหม่ ถ้าติ๊ก "ยังรอยืนยัน" จะร่างเป็นคำถามขอความเห็น
  - ใส่กำหนดตอบกลับและเหตุผลได้ (ระบบเติมจากกำหนดและรายละเอียดของงานที่เลือกให้ก่อน)
  - **แบบสั้น** (แชตรายคน) หรือ **แบบแยกข้อ** (ไลน์กลุ่ม) แก้ไขร่างได้ในกล่อง
  - ข้อมูลที่ขาดจะเป็นช่อง `[ชื่อผู้รับ]` `[เวลาที่ต้องการคำตอบ]` และขึ้นรายการ "ยังมีช่องที่ต้องเติม" ให้พิมพ์แล้วกดใส่
  - **คัดลอกข้อความ** คัดลอกเฉพาะข้อความพร้อมส่ง หรือกด **เปิดใน LINE**
  - จำผู้รับที่ใช้ล่าสุดไว้ให้กดซ้ำได้
- **ตั้งค่า** (ไอคอนเฟืองมุมขวาบนหน้าแรก) แก้ "เกี่ยวกับผม" ที่ AI ใช้เป็นตัวตนตอนเขียน, ใส่รหัสแอป, ดาวน์โหลด/นำเข้าไฟล์สำรอง, เลือกโหมดสว่าง/มืด, ลบงานตัวอย่าง
- **ติดตั้งบนมือถือ** เป็นแอป (PWA) เปิดได้แม้สัญญาณหลุด (AI ต้องใช้เน็ต)

แอปทำงานได้ 2 ระดับ:

| ระดับ | ต้องตั้ง | ได้อะไร |
|---|---|---|
| 0 | ไม่ต้องตั้งอะไร | ทุกอย่างทำงาน สรุปและร่าง LINE ใช้ **ร่างมาตรฐาน** จากรายการงาน (ยังอ่านโน้ตประชุมไม่ได้) |
| 1 | `ANTHROPIC_API_KEY` | Claude อ่านโน้ตและข้อความแชต แยกมติกับข้อเสนอ ยึดข้อสรุปล่าสุด และเขียน LINE ในน้ำเสียงของพัตเตอร์ ถ้า AI ล่มจะกลับไปใช้ร่างมาตรฐานเอง |

## ข้อมูลเก็บที่ไหน
ไม่มี login จึงเก็บข้อมูลใน**เบราว์เซอร์ของเครื่องนั้น** (localStorage) ไม่ส่งไปเก็บที่เซิร์ฟเวอร์
เปลี่ยนเครื่องหรือเบราว์เซอร์ให้ใช้ ตั้งค่า → ดาวน์โหลดไฟล์สำรอง แล้วนำเข้าที่เครื่องใหม่
ตอนกดสรุปหรือร่าง LINE ด้วย AI เฉพาะงานที่เลือก โน้ต และข้อความ "เกี่ยวกับผม" จะถูกส่งไปประมวลผลที่ Anthropic API และไม่ถูกบันทึกที่เซิร์ฟเวอร์ของแอป ควรตรวจนโยบายข้อมูลของ ปตท. ก่อนวางข้อมูลลับ

## โครงสร้าง
```
index.html          หน้าแอปทั้งหมด (ไม่มีขั้นตอน build) รวมร่างมาตรฐานที่ทำงานในเครื่อง
api/summarize.js    POST: งาน + โน้ต → สรุปให้หัวหน้า/ทีม (Claude)
api/line-draft.js   POST: งาน + ผู้รับ + จุดประสงค์ → ร่างข้อความ LINE (Claude)
api/help.js         POST: บทสนทนา + โครงการ/งาน → คำตอบและ actions ของ Putter Help (Claude)
api/config.js       GET: บอกหน้าเว็บว่าเปิด AI / รหัสแอปไว้ไหม
api/_lib.js         ตัวช่วยร่วม: ตรวจรหัสแอป เรียก Claude ตัวตนของผู้ใช้
sw.js, manifest.webmanifest, icon*.png   PWA
```
แก้สีแบรนด์ที่ตัวแปร `--brand`, `--brand-hi`, `--night` บนสุดของ `<style>` ใน `index.html`

## Deploy บน Vercel
1. เปิดโปรเจกต์ของ repo นี้ใน Vercel (ถ้าเคยตั้งเป็น Next.js ไว้ `vercel.json` ตั้ง `framework: null` ให้แล้ว หรือเปลี่ยน Framework Preset เป็น **Other** และลบ Build Command)
2. Environment Variables (ดู `.env.example`):
   - `ANTHROPIC_API_KEY` จาก platform.claude.com (ไม่ใส่ก็ได้ จะใช้ร่างมาตรฐาน)
   - `APP_PIN` (ไม่บังคับ) รหัสสั้น ๆ กันคนที่รู้ลิงก์มาใช้ AI ของเรา ใส่ครั้งเดียวที่หน้าตั้งค่าของแอป ไม่ใช่การ login
3. Deploy แล้วเปิดเว็บ ตัวแปรเก่าของ Workier (`NEXT_PUBLIC_FIREBASE_*`, `WORKIER_SECRET`, `ANTHROPIC_MODEL`) ไม่ได้ใช้แล้ว ลบได้

## ทดสอบในเครื่อง
```bash
npm install
npx vercel dev      # เปิด http://localhost:3000 พร้อม API
```
